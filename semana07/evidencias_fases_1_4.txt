  ┌────────────────┬────────┬────────────────────┬─────────────────┐
  │    Cliente     │ Ciudad │ Pedidos entregados │ Monto acumulado │
  ├────────────────┼────────┼────────────────────┼─────────────────┤
  │ Carlos Mendoza │ Bogotá │ 2                  │ $165.000        │

  Consulta usada:
  SELECT c.id, c.nombre, c.ciudad,
         count(p.id) AS pedidos_entregados,
         coalesce(sum(p.monto), 0) AS monto_total

  LEFT JOIN pedidos p

  WHERE c.ciudad = 'Bogotá'
  GROUP BY c.id, c.nombre, c.ciudad
  ORDER BY monto_total DESC;

❯ ¿Cuál es el porcentaje y el monto de facturación correspondiente a pedidos en 
  estado CANCELADO en comparación con los pedidos ENTREGADOS?                   

  Called postgres-domicilios (ctrl+o to expand)

● Los pedidos cancelados suman $150.000, es decir, el 31,85% de lo que suman
  cancelados y entregados juntos ($471.000).

  ┌───────────┬─────────┬──────────┬─────────────────┬──────────────────────┐
  │           │         │          │    % sobre      │   % sobre toda la    │
  │  Estado   │ Pedidos │  Monto   │  cancelado +    │     facturación      │
  │           │         │          │    entregado    │      ($506.000)      │
  ├───────────┼─────────┼──────────┼─────────────────┼──────────────────────┤
  │ ENTREGADO │ 4       │ $321.000 │ 68,15%          │ 63,44%               │
  ├───────────┼─────────┼──────────┼─────────────────┼──────────────────────┤
  │ CANCELADO │ 1       │ $150.000 │ 31,85%          │ 29,64%               │
  └───────────┴─────────┴──────────┴─────────────────┴──────────────────────┘

  Lectura de los números:
  - Por cada $100 entregados se cancelan unos $46,73, porque $150.000 equivale
    al 46,73% de $321.000.
  - Todo el monto cancelado viene de un solo pedido, el #5 de Roberto Silva. Ese
    pedido es además el más caro de la base: vale más que cualquier pedido
    entregado y casi la mitad de todo lo entregado.
  - Calculado sobre toda la facturación, el 6,92% restante corresponde al pedido
    #3, que sigue EN_CAMINO ($35.000).

  Con solo 6 pedidos, una sola cancelación cambia mucho estos porcentajes.
  Sirven para el taller, pero no para sacar conclusiones de negocio.

  Consulta usada:
  WITH t AS (
    SELECT estado, count(*) AS pedidos, sum(monto) AS monto
    FROM pedidos
    WHERE estado IN ('CANCELADO', 'ENTREGADO')
    GROUP BY estado
  )
  SELECT estado, pedidos, monto,
         round(100.0 * monto / sum(monto) OVER (), 2) AS pct_sobre_ambos,
         round(100.0 * monto / (SELECT sum(monto) FROM pedidos), 2) AS
  pct_sobre_total,
         round(100.0 * monto / (SELECT monto FROM t WHERE estado = 'ENTREGADO'),
  2) AS pct_vs_entregado
  FROM t
  ORDER BY estado;

❯ ¿Cuál es el valor promedio de compra por pedido agrupado por ciudad del       
  cliente?                                                                      

  Called postgres-domicilios (ctrl+o to expand)

● Contando todos los pedidos, Bogotá tiene el promedio más alto ($105.000).
  Contando solo los entregados, el más alto es Cali ($89.000). Muestro las dos
  versiones porque la pregunta no aclara si se incluyen cancelados y pedidos en
  camino:

  ┌──────────┬─────────┬──────────┬───────────┬─────────────┬───────────────┐
  │          │         │  Monto   │ Promedio  │  Pedidos    │   Promedio    │
  │  Ciudad  │ Pedidos │  total   │  (todos)  │ entregados  │    (solo      │
  │          │         │          │           │             │  entregados)  │
  ├──────────┼─────────┼──────────┼───────────┼─────────────┼───────────────┤
  │ Bogotá   │ 3       │ $315.000 │ $105.000  │ 2           │ $82.500       │
  ├──────────┼─────────┼──────────┼───────────┼─────────────┼───────────────┤
  │ Cali     │ 1       │ $89.000  │ $89.000   │ 1           │ $89.000       │
  ├──────────┼─────────┼──────────┼───────────┼─────────────┼───────────────┤
  │ Medellín │ 2       │ $102.000 │ $51.000   │ 1           │ $67.000       │
  └──────────┴─────────┴──────────┴───────────┴─────────────┴───────────────┘

  Por qué cambia el orden:
  - Bogotá encabeza con todos los pedidos porque incluye el pedido cancelado de
    $150.000. Si se quita, su promedio baja a $82.500 y pasa a segundo lugar.
  - Cali queda primero con solo entregados. Tiene un único pedido, así que su
    promedio es simplemente ese valor.
  - Medellín sube de $51.000 a $67.000 al excluir el pedido #3 de $35.000, que
    sigue EN_CAMINO.

  Para medir ventas reales, la columna de solo entregados es la más
  representativa. De todos modos, con 1 a 3 pedidos por ciudad estos promedios
  no alcanzan para comparar ciudades con confianza.

  Consulta usada:
  SELECT c.ciudad,
         count(p.id) AS pedidos,
         sum(p.monto) AS monto_total,
         round(avg(p.monto), 2) AS promedio_todos,
         count(p.id) FILTER (WHERE p.estado = 'ENTREGADO') AS
  pedidos_entregados,
         round(avg(p.monto) FILTER (WHERE p.estado = 'ENTREGADO'), 2) AS
  promedio_entregados
  FROM clientes c
  JOIN pedidos p ON p.cliente_id = c.id
  GROUP BY c.ciudad
  ORDER BY promedio_todos DESC;
